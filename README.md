# Calculadora MVC - Java SE

Aplicación de escritorio (stand-alone) desarrollada en Java SE con el patrón MVC. Realiza las operaciones básicas: suma, resta, multiplicación y división.

## Tecnologías

- Java SE
- Swing
- Lombok
- JUnit 4.13.2
- Maven

## Estructura

- `src/main/java/modelo/` → Modelo
- `src/main/java/vista/` → Vista
- `src/main/java/controlador/` → Controlador
- `src/test/java/modelo/` → Pruebas unitarias
- `docs/diagrama-clases.jpeg` → Diagrama UML
